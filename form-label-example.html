Connecting a field label to its input

A local example based on the first-name field captured from Secura Home's public contact page. The first sample retains the missing label connection; the second shows the proposed change.

Click First Name* above each box and compare which input receives focus. No personal information is needed.

The change in code

<label for="first-name">First Name*</label>
<input id="first-name" name="first_name" type="text">

The original name and type are preserved. This example checks one label relationship; it is not a replacement for the complete form.

Local browser interaction and screen-reader behaviour have not yet been tested. The live site has not been changed.
